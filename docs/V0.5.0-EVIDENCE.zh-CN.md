## 逐项记录

### E01：称呼方向

Fixture 在 `src/v2.test.ts` 的 `v2 addresses` 中使用同一 literal，同时写入 `user→assistant` 和
`assistant→user`，断言两条记录 id 不同、均可按各自规则 active，brief 显示两个方向；assistant 来源的 hint
被拒绝；同一消息同时从两条输入路径提交时 evidence 只计一次；只 forget `user→assistant` 后另一方向保持存在并可 confirm。

### E02：观察与偏好分离

`src/memory.test.ts` 的 profile hint fixture 只接受具体回应结构、协作和解释偏好，拒绝人格/心理标签；
structured brief 与 response preference 测试分别断言用户观察和 agent 回应偏好字段。用户消息长度本身没有被作为回应长度证据。

### E03/E04：表达模式

`src/v2.test.ts` 断言带 `behaviorSummary`、`functions` 和 `variationPolicy` 的模式在两个 session、三次观察后才 active，
文档示例不会预填；`distill_recent_style` 的每项只增加一次低权重观察，不能绕过激活门槛。六个候选写入 brief 时只选两个。
同一测试还断言 `。。。` 字符序列原样保留，并且同轮 feedback forget 后不被 hints 重建。`src/extract.test.ts` 覆盖 emoji、颜文字、笑声、特殊标点和中英混用的低层提取。

### E05：评分

`src/memory.test.ts` 的 score fixture 覆盖 readiness/stability/freshness/drift/over-imitation 结果、revision refresh 建议和 profile preference
的明确写入。它证明评分 API 可运行和字段边界不混淆，但当前仓库没有目标模型 tokenizer、真实 API usage 或完整外部标注集；因此不把本地
TypeScript 测试描述成跨模型评分校准。

### E06：brief 与 token

`src/v2.test.ts` 断言 bootstrap 返回 channel/policy、已知 revision 返回 ack、过期 revision 返回 delta、delta 不重复完整 brief、
六段顺序存在以及典型表达模式只渲染两项。`docs/V0.5.0-TOKEN-REPORT.zh-CN.md` 记录了为什么这些结构断言不能替代真实 token measurement。

### E07/E09：安全边界

`src/memory.test.ts`、`src/store.test.ts` 和 `src/cleanup.test.ts` 覆盖敏感消息/例子过滤、损坏 store 的可解释恢复、并发观察、
candidate 30 天、active 180 天、archived 360 天边界和 pinned 保护。自动 TTL 仅处理表达模式；称呼、明确偏好和 failure log 使用独立路径。

### E08：迁移

`src/store.test.ts` 覆盖 v2 normalization、旧字段兼容、固定绝对 data path 和腐坏根形状；安装 fixture 在
`scripts/install-or-upgrade.test.mjs` 中先放入带 `legacy-emoji` 的 v1 store，安装后断言版本为 2、literal `。。。` 和 host config 保留，
并检查 store backup 存在。重复安装不产生 backup 风暴。

### E10：隔离安装/回滚

安装测试从 `runtime/0.4.0` 与 v1 store 开始，正常路径切换到 `runtime/0.5.0`，通过 launcher 连接三个独立 session，断言三份 capsule
一致且 sessionId 各自保留。连续三次同版本安装返回 `ALREADY_ACTIVE` 且 store/config/instruction hash 不变；并发安装一成功一返回 `LOCKED`。
`build`、`migrate`、`config`、`switch`、`server`、`handshake` 六个 fault point 均断言返回 `ROLLED_BACK`，旧 runtime、store 和 host 文件
hash 恢复；死进程 stale lock 可恢复。所有路径都在临时 fixture 中运行。

## 未覆盖与剩余风险

- E06 的真实 20 回合成本、目标模型 tokenizer、cached input 和至少两种目标 agent 的生成质量尚未在当前环境执行；不能把字符数换算成 token。
- E01/E03 计划中的大规模人工标注和两个目标 agent 生成层实验，本地单元 fixture 只覆盖确定性协议边界；不能把它们扩大表述为模型行为统计。
- 证据索引不等于发布授权。计划状态只有在本地实验、最终全量命令和唯一的只读 `gpt-5.6-sol` reviewer 都完成后才能最终标绿。
